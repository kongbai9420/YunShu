# 用户、角色与资产范围

## 三种角色

| 角色 | 能做什么 |
| --- | --- |
| 管理员 | 全部功能：用户管理、审计日志、控制归属切换、开启 BMC 的 SNMP、自定义巡检模板、AI 与漏洞情报设置、外观默认值与主题导入、回收站彻底删除与保留期、型号库导入 |
| 运维 | 查看并修改资产、端点、凭据、告警规则与通知、拓扑；执行电源与温控操作；建巡检任务、立即巡检；从回收站恢复资产；标记服务器告警已处理 |
| 只读 | 只能查看；没有权限的按钮显示为灰色并说明原因 |

在“平台设置 → 用户与角色”新建用户、修改角色、重置临时密码。用户用临时密码登录后必须先改密码；重置后该用户的其他登录会话会被注销。

### 登录与会话

- 初始管理员 `admin` / `admin123`，第一次登录必须先改密码。
- 登录会话 24 小时，有访问就顺延。
- 登录失败锁定：同一来源 + 同一账号 5 分钟内失败 5 次，锁这一组 5 分钟；同一来源合计失败 30 次，锁整个来源 5 分钟。经反向代理访问时请正确设置 `FORWARDED_ALLOW_IPS`，见 [部署与运行](deployment.md)。
- 每个人可以在“平台设置 → 我的账户”修改自己的密码。

## 资产范围

在角色之上，再限定一个账号**能看到和操作哪些资产**。在用户列表里点“资产范围”：

- **可见全部资产**：不限制。升级前已有的账号默认如此，管理员始终可见全部。
- 取消后，按**场所**授权（包含它的全部下级场所，以后新增的下级场所也自动包含），再加上**单独授权的资产**。
- 宿主可见不会自动带出它上面的虚拟机，虚拟机按自己的场所或单独授权。
- 取消“可见全部”且一项都不选时，这个账号看不到任何资产。
- 保存后可以预览“实际可见的资产”。

范围外的资产、告警、任务、操作记录、拓扑连线、指标、巡检报告条目、服务器告警、漏洞命中都完全不显示，实时推送和导出里也没有；直接打开范围外资产的链接会提示“资产不存在或你无权查看”。控制操作在入队时和执行前都会按发起人当前的范围检查，撤销授权后未执行的操作会被拒绝。

部分全局配置（告警规则、通知渠道、维护窗口、网段发现、拓扑编辑、温控曲线、Worker 状态）只对“可见全部资产”的账号开放。

## 单点登录（OIDC，可选，默认关闭）

支持 Keycloak、Authentik、Azure AD 等标准 OIDC 身份提供方；公司的 LDAP / AD 可以先接入这些身份提供方，再由它们对接平台。

1. 在身份提供方建一个客户端，回调地址填 `https://<平台地址>/api/auth/oidc/callback`。
2. 设置环境变量（见 [配置项参考](configuration.md)）：

   ```ini
   YUNSHU_OIDC_ISSUER=https://sso.example.test/realms/ops
   YUNSHU_OIDC_CLIENT_ID=yunshu
   YUNSHU_OIDC_CLIENT_SECRET=fake-client-secret
   YUNSHU_OIDC_REDIRECT_URL=https://yunshu.example.test/api/auth/oidc/callback
   YUNSHU_OIDC_ADMIN_GROUPS=ops-admins
   YUNSHU_OIDC_OPERATOR_GROUPS=ops-team
   ```

3. 重启后登录页出现“单点登录”按钮。

规则：

- 账号按身份提供方的用户标识识别；**不会接管同名的本地账号**（同名时拒绝登录，需要管理员处理）。
- 角色按身份提供方的组（groups）映射，每次登录同步：在管理员组里为管理员，在运维组里为运维，否则为只读。
- 新建的单点登录账号默认**看不到任何资产**，由管理员设置资产范围（`YUNSHU_OIDC_SCOPE_ALL=1` 可改为默认可见全部）。
- 单点登录账号不能用密码登录；本地 `admin` 始终可用，作为应急账号。

## 只读 API 令牌

“平台设置 → API 令牌”：

- 每个账号最多 10 个，**只在创建时显示一次**，平台只保存哈希。
- 权限和资产范围与创建它的账号相同，只能读取。
- 用途：Prometheus 抓取 `/metrics`（见 [监控、告警与巡检](monitoring-alerts.md)），以及外部 AI 工具访问只读 MCP 接口 `/mcp`（需在“平台设置 → AI”里开启）。
- 不用时请删除。令牌泄露后，持有者能读取你可见资产的指标。

## 审计日志

管理员在“平台设置 → 审计日志”查看登录、配置修改、控制操作、导入、令牌创建、巡检模板修改、漏洞处置等记录。详情里的密码、令牌类字段在写入前替换为 `***`。默认保留 365 天（`YUNSHU_AUDIT_RETENTION_DAYS`）。
