# 外观与主题

外观分两个维度，分开选：

| 维度 | 选项 |
| --- | --- |
| 风格 | **简洁**：不透明的浅灰 / 深灰界面；**玻璃**：半透明毛玻璃表面、悬浮的顶栏与侧栏、背后有壁纸；或管理员导入的主题 |
| 深浅 | 跟随系统、浅色、深色。跟随系统时按电脑或手机的深色模式自动切换 |

外观只改显示，不影响数据和权限。

## 自己的外观

“平台设置 → 外观 → 我的外观”，或点顶栏的调色盘按钮。

- 只影响你自己，跟账号保存，换电脑登录也一样。
- 选“平台默认”时跟随管理员的设置。

## 平台默认（管理员）

“平台设置 → 外观 → 平台默认”设置默认风格和默认深浅。

- 新账号和没有自己选过的账号用这里的设置；选了“平台默认”的账号刷新后生效。
- 登录页按这台浏览器上次的外观显示。
- 默认风格是“简洁”。玻璃效果更耗显卡，老电脑或远程桌面里可能卡顿；系统开了“降低透明度”或浏览器不支持背景模糊时，玻璃会自动改成不透明。

## 玻璃主题壁纸（管理员）

“平台设置 → 外观 → 玻璃主题壁纸”：

- 不上传时用内置的彩色渐变。
- 上传 PNG、JPEG 或 WebP，最大 4 MB。颜色柔和的图片效果最好，文字更清楚。
- 只在玻璃风格（以及基于玻璃的主题）下显示，深色模式下自动压暗。所有用玻璃风格的账号都会看到这张图。
- 图片存在平台数据库里，随备份一起保存。可以随时“改回内置渐变”。

## 导入主题包（管理员）

主题包是一个 JSON 文件，只能改颜色、圆角、阴影、渐变这类**变量的值**，不能带脚本、外部图片或样式规则。导入后所有账号都能选用。

在“平台设置 → 外观 → 导入的主题”里可以“下载示例主题包”，改好颜色再导入。

```json
{
  "format": "yunshu-theme",
  "version": 1,
  "id": "ocean",
  "name": "海洋",
  "base": "glass",
  "author": "example.invalid",
  "description": "一句话说明",
  "theme_version": "1.0.0",
  "light": { "primary": "#00668a" },
  "dark": { "primary": "#4fb3d9" }
}
```

| 字段 | 规则 |
| --- | --- |
| `id` | 小写字母开头，只能有小写字母、数字和 `-`，2–32 个字符；不能是 `simple` 或 `glass`。同一 id 再导入会覆盖原来的 |
| `name` | 显示名称，最多 40 个字符 |
| `base` | 基于哪个风格：`simple`（简洁）或 `glass`（玻璃）。没写的变量沿用基础风格的值 |
| `light` / `dark` | 浅色、深色下要改的变量；变量名写不写前导 `--` 都可以。两个都不写会被拒绝 |

值的限制：

- 允许：颜色（`#rrggbb`、`rgb()`、`rgba()`、`hsl()`、`oklch()`、`color-mix()`）、长度（`1rem`、`24px`）、阴影、渐变（`linear-gradient()` 等）、`calc()`。
- 不允许：引号、分号、花括号、反斜杠，以及 `url()`、`var()`、`image-set()` 这类函数。
- 每个值最多 600 个字符，整个文件最大 64 KB，最多导入 20 个主题。

常用变量：`background` / `foreground`（页面底色 / 正文）、`card`、`sidebar` / `titlebar`、`primary`（主按钮、侧栏当前项）、`border`、`radius`、`status-ok` / `status-warn` / `status-bad`（状态色），玻璃专用的 `app-backdrop`（壁纸渐变）、`glass-blur`、`glass-edge` 等。

**完整的变量清单和做主题的注意事项**见仓库里的 [主题说明](https://github.com/kongbai9420/YunShu/blob/main/frontend/src/themes/README.md)。做主题时请检查：

- 正文对背景的对比度至少 4.5:1；玻璃主题按背后最亮或最暗的壁纸区域算。白字放在 `primary` 上也要达到 4.5:1。
- 浅色、深色都要试；深色模式下状态色要换成亮一些的版本。

删除一个主题后，用它的账号和平台默认会退回“简洁”。
