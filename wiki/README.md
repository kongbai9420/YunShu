# 云枢运维平台

云枢（YunShu Ops）是一个**无 Agent** 的基础设施运维平台：不用在被管设备上装任何程序，通过设备本来就有的管理协议（SNMP、SSH、IPMI、Redfish、Proxmox VE / vSphere API）读取数据，必要时发送受控的电源与风扇命令。

本文档面向**部署和使用平台的人**：怎么装、怎么配、怎么接设备、出了问题怎么查。

> **测试版说明**：当前版本 4.4.0-beta.1。所有设备适配目前**只用模拟设备和伪造数据测试过**，真实硬件验证仍在进行。请先在测试环境试用；对真实设备执行写操作（电源、风扇、在 BMC 上开启 SNMP 或推送）前，先在非生产设备上确认。

## 适合谁

| 场景 | 推荐部署 |
| --- | --- |
| 个人、家庭实验室、NAS 上跑着玩 | 轻量版：一条 `docker run`，或 Windows 免安装包 |
| 小机房、几个人一起用 | 轻量版（Compose），或 Linux 安装包 / Windows 服务版 |
| 中小企业，几百到上千台资产 | 标准版：PostgreSQL |
| 资产多、采集重，已有 DBA 维护数据库 | 企业版：独立 PostgreSQL + 多个 Worker |

## 能做什么

| 方面 | 内容 |
| --- | --- |
| 资产 | 资产台账（形态 / 角色 / 平台互相独立）、管理端点与加密凭据、批量导入、网段发现、资产关系；删除先进回收站 |
| 采集 | SNMP、SSH、IPMI、Redfish、PVE API、ESXi / vCenter、TCP 可达性；服务器 BMC 自动探测各协议能读到什么，生成采集计划；SSH 读取软件包清单 |
| 监控 | 指标历史（原始 / 分钟 / 小时三级保留）、实时推送、仪表盘、资源全景 |
| 告警 | 阈值与可达性规则、上游故障抑制、维护窗口、邮件与多种机器人通知；“服务器告警”板块逐条查看 BMC 硬件事件，可选 SNMP Trap 与 Redfish 事件推送 |
| 巡检 | 每日巡检报告；命令巡检（内置 Linux、PVE、华为、H3C、Cisco 只读模板，可定时，拦截危险命令） |
| 漏洞情报 | 多个数据源逐个启用；按固件与软件包版本比对本地影响；同一漏洞多来源合并通知 |
| AI 助手（可选） | 默认关闭、只读：漏洞影响分析、告警解读、巡检摘要、问答助手、只读 MCP 接口 |
| 运维操作 | IPMI 电源、风扇温控曲线与熔断；经 PVE / vSphere 开关虚拟机；在 BMC 上开启 SNMP 与推送（默认关闭） |
| 拓扑与机柜 | LLDP 候选链路人工确认、多视图布局；机柜 U 位、设备型号库、按 MAC / IP 找交换机端口 |
| 权限 | 管理员 / 运维 / 只读，按场所与资产划分范围；可选 OIDC 单点登录；只读 API 令牌与 Prometheus `/metrics` |
| 外观 | “简洁”与“玻璃”两种风格，浅色 / 深色 / 跟随系统；可导入主题包 |
| 部署 | Docker（amd64 / arm64，适合 NAS）、Linux 安装包（systemd）、Windows MSI 服务版、Windows 免安装包 |

## 工作方式

```
浏览器 ──HTTP(S)──▶ API（页面与接口）──┐
                                        ├──▶ 数据库（SQLite 或 PostgreSQL）
        Worker（采集、告警、定时任务）──┘
              │
              └──▶ 设备：SNMP / SSH / IPMI / Redfish / PVE API / vSphere API
```

- **API**：提供网页和接口，负责登录、权限和所有配置。
- **Worker**：按计划采集指标、判断告警、发送通知、执行控制任务和巡检。轻量版里 Worker 和 API 在同一进程；标准版、企业版单独运行一个或多个 Worker。
- **数据库**：保存资产、指标、告警、操作记录。设备密码用**主密钥**加密后保存，主密钥单独存放，**请单独备份**。

## 页面上的「!」

每个设置项都有说明：一句话能说清的写在输入框下方；说不清的在标签旁放一个「!」胶囊，鼠标悬停、键盘聚焦或手机点按就能看到详细说明（做什么、默认值、例子、影响）。**橙色**的「!」表示这个选项会影响设备或数据，修改前请仔细阅读。
